Before I start to explain it, I just wanna say that it is vibe coded. I don't have coding knowledge and i created this tool just so i can practice. I'm now publishing it so others can practice too.

Basically, there are a couple of mechanics and gimmicks.

You first have to create an account, stored in a .json file in the same folder as the python file. 
There are 3 things you have to enter in order to create an account.
Your shown username, your player id (which is used for logging in, trading, sending gifts etc.) and a password. 
There is a DEV testing account with the following ID and password:

After you create an account, you will be taken to the lobby where you have your main menu. 

The first options is the games menu. You can play the chords games from here as well as a casino.
I won't go into the full details with the casino system since it's basically useless, but a fun break from the normal chords mode.

The chords game mode has some different options. 

There's the normal mode where you pick a difficulty from easy-medium-hard-extreme
The easy, medium, hard and extreme difficulties shows 4-1 notes of each chords respectively.

The normal chords mode shows you notes and gives you 4 chords to pick out of.
The timed mode has a 60 second countdown.
The memory mode is useless for now.
The endless mode is also useless for now.
The name the chords mode gives you a chord and you need to write the notes of that chord.

You can gain a currency called Pointy by playing the game modes, playing in the casino or by completing the achivements.
You can use this currency to buy stuff the Pointy shop.

There are consumables which gives you temporary boosts.
There are Permanent upgrades which give you permanent boosts.
There are titles that will show in your profile or the leaderboards.
There are titles Tradable collectibles which can be used to trade with other players.
There are mystery boxes which can give you pointys, eggs, titles, themes, tradables etc.
There are eggs you can buy.

Now to the pets mechanic.
You can hatch eggs into pets. Pets give you boosts and you can level them up.
There are 7 rarities and 29 pets in total.
common, rare, epic legendary, mythic, divine, secret
The rarer the egg, higher the chance for a rarer pet.
You can evolve pets and they have a chance to be mutated.

There are inventory, trading, prestige systems too but they're kinda useless.

There's a level system and if you reach 50 levels, you can upgrade your prestige level by +1, resetting your level to 0 and giving you a perminant boost.
This feature can stack up.

Trading is still kinda buggy so I'm still working on that.
But basically, you can trade coins and stuff with the players on the device.
You can see trade offers and unlocked achievements through the notification menu and read them.
you can accept or decline the trade offers through Trading-View Incoming Trades

That's basically it. I tried to make learning chords more fun and I believe i actually improved a little.
